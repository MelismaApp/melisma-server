## Code Graph (codegraph)

A local knowledge graph of this codebase is available via the codegraph MCP server.

**Always use graph tools before answering questions about the codebase:**
- `query_graph` — find relevant nodes before reading files
- `get_neighbors` — understand what a symbol connects to
- `shortest_path` — trace relationships between two concepts
- `god_nodes` — find the most important abstractions
- `affected` — understand blast radius before making changes

Rebuild after major changes: `codegraph extract`
Update incrementally after small changes: `codegraph update`
